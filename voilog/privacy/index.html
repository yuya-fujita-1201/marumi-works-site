プライバシーポリシー

最終更新日: 2026年5月13日

VoiLog（ボイログ）（以下「本アプリ」）は、まるみワークス（Marumi Works、以下「当社」）が提供するiOSアプリケーションです。本プライバシーポリシーでは、本アプリにおける個人情報の取り扱いについて説明します。

1. 収集する情報

本アプリでは、以下の情報を取り扱います。氏名・メールアドレス・電話番号などの個人を特定できる情報は一切取得しません。

マイク音声：ユーザーが録音操作を行った際にマイクから取得する音声データです。録音はユーザーの明示的な操作（録音開始ボタンのタップ等）によってのみ開始されます。

画面音声（画面音声録音モードのみ）：iOS の Broadcast Upload Extension を利用して取得する、Zoom / Teams / Meet 等のオンライン会議の音声データです。録画ではなく音声のみを処理し、画面の映像は取得しません。

OpenAI API キー（会議モード／画面音声録音モードを利用する場合）：ユーザーがご自身で OpenAI 社から取得し、設定画面に入力した API キー文字列です。この情報は端末の Keychain にのみ保存され、当社のサーバーには送信されません。

録音ファイルおよび文字起こしテキスト：録音した音声ファイルと、その文字起こし結果のテキストデータ。お使いの端末内のローカルストレージにのみ保存されます。

2. 情報の利用目的

収集した情報は以下の目的でのみ使用します。

・録音および文字起こし機能の提供

・ユーザーが選択した認識エンジン（Apple 音声認識 / OpenAI Whisper）への音声データの送信

・録音履歴の管理および端末内への保存

3. 第三者への情報提供

本アプリは、ユーザーが選択した録音モードに応じて、以下の第三者サービスに音声データを送信します。送信はユーザーが当該モードを選択して録音を実行した場合にのみ行われ、ユーザーの明示的な選択なく行われることはありません。

Apple 音声認識（SFSpeechRecognizer / マイク録音モード）：マイク録音モードでは、リアルタイムに文字起こしを行うため、録音した音声を Apple Inc. の音声認識サーバーに送信します。送信されたデータの取り扱いは Apple のプライバシーポリシーに従います。Apple のプライバシーポリシーは https://www.apple.com/legal/privacy/jp/ をご参照ください。

OpenAI API（会議モード／画面音声録音モード）：会議モードおよび画面音声録音モードでは、ユーザーが設定画面に登録した API キーを用いて、録音した音声を OpenAI, L.L.C. が提供する音声認識 API（gpt-4o-mini-transcribe）に送信し、文字起こしを実行します。当該 API への送信は、ユーザーご自身の OpenAI アカウントから行われ、利用料金はユーザーが直接 OpenAI に支払う形態（BYOK：Bring Your Own Key）です。当社は OpenAI への送信内容を取得・保存しません。OpenAI のプライバシーポリシーは https://openai.com/policies/privacy-policy をご参照ください。OpenAI による API データの取扱いについては https://openai.com/policies/api-data-usage-policies をご参照ください。

上記以外の第三者への個人情報の提供は、法令に基づく場合を除き、ユーザーの同意なく行いません。

4. データの保管と削除

録音ファイル・文字起こしテキストは、お使いの端末内のローカルストレージにのみ保存されます。当社のサーバーには一切保存されません。

アプリ内で録音を削除すると、対応するデータは端末から完全に削除されます。また、アプリをアンインストールすることで、Keychain に保存された OpenAI API キーを含め、本アプリに関連するすべてのデータが端末から削除されます。

5. OpenAI API キーの取り扱いについて

本アプリは、OpenAI API キーをユーザーご自身で取得・管理いただく BYOK（Bring Your Own Key）方式を採用しています。これにより、ユーザーは音声データの送信先・利用料金・利用量を直接コントロールできます。

入力された API キーは iOS の Keychain（OS が提供する暗号化された安全な保管領域）にのみ保存され、当社を含む第三者には送信されません。アプリの設定画面からいつでも削除できます。

API キーは秘密の情報です。SNS への投稿やスクリーンショットでの共有は絶対に行わないでください。万一漏えいした場合は、OpenAI のダッシュボード（https://platform.openai.com/api-keys）から該当キーを直ちに無効化（Revoke）してください。

6. トラッキング・広告について

本アプリは、Apple ATT（App Tracking Transparency）フレームワークを使用したトラッキングを行いません。第三者の広告ネットワーク・解析 SDK は一切組み込まれていません。広告も表示されません。

7. お子さまのプライバシー

本アプリは 4 歳以上を対象としていますが、業務利用・成人ユーザーを主たる対象としています。13 歳未満のお子さまから個人を特定できる情報を意図的に収集することはありません。お子さまが本アプリを利用される場合は、保護者の方の管理・監督の下でご利用ください。

8. プライバシーポリシーの変更

当社は、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、アプリ内または本ページにて通知します。
