利用規約

最終更新日: 2026年5月13日

この利用規約（以下「本規約」）は、まるみワークス（Marumi Works）が提供するiOSアプリケーション VoiLog（ボイログ）（以下「本アプリ」）の利用条件を定めるものです。ユーザーの皆様には、本規約に同意いただいた上で本アプリをご利用いただきます。

第1条（適用）

本規約は、ユーザーと当社との間の本アプリの利用に関わる一切の関係に適用されます。

第2条（利用条件）

本アプリは iOS 16 以降を搭載した iPhone にてご利用いただけます。音声録音にはマイクへのアクセス許可が必要です。マイク録音モードでの文字起こしには Apple 音声認識へのアクセス許可とインターネット接続が必要です。会議モードおよび画面音声録音モードを利用するには、ユーザーご自身が OpenAI から取得した API キーの登録と、別途インターネット接続が必要です。

第3条（OpenAI API キーおよび利用料金について）

本アプリは、会議モードおよび画面音声録音モードにおける文字起こし機能として、OpenAI 社の音声認識 API（Whisper / gpt-4o-mini-transcribe 等）を利用します。当該機能を利用するためには、ユーザーが OpenAI 社から発行を受けた API キーを設定画面に登録する必要があります。これは BYOK（Bring Your Own Key）方式です。

API の利用に伴って発生する料金は、すべてユーザーが直接 OpenAI 社に対して負担するものとし、当社は一切の支払い義務を負いません。料金の単価および請求条件は OpenAI 社の定めるところによります。当社は OpenAI 社の料金設定の変更について責任を負いません。

API キーの管理はユーザーの責任において行ってください。API キーの漏えい・不正利用等によって発生したいかなる損害（不正利用による高額請求等を含む）についても、当社は一切の責任を負いません。

第4条（録音について）

本アプリは、ユーザーが録音操作を行った際にのみ音声を取得します。録音内容に第三者の音声が含まれる場合、ユーザーは録音地の法令・社内規程・参加者の合意その他必要な許諾の下で録音を行うものとし、当該録音が違法ないし不適切なものでないことを保証するものとします。当社は、ユーザーによる録音内容に起因する一切の紛争・損害について責任を負いません。

画面音声録音モードは、Zoom / Microsoft Teams / Google Meet 等のオンライン会議ツールの音声を取得することを想定しています。ご利用にあたっては、各オンライン会議ツールの利用規約および会議参加者の合意を遵守してください。

第5条（AI による文字起こしについて）
