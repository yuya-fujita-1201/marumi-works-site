サポート

VoiLog（ボイログ） をご利用いただきありがとうございます。アプリに関するご質問やお困りごとがございましたら、以下をご確認ください。

はじめての方へ

Q. 3 つの録音モードの違いを教えてください

マイク録音は iPhone のマイクから録音して、iOS 標準の音声認識でリアルタイムに文字起こしします。料金はかかりません。1 人の音声メモや近距離の会話に最適です。
会議モードは OpenAI の高精度な音声認識エンジン（Whisper 系）を使用します。離れた声や複数人での会議に向いていますが、文字の表示まで 30 秒ほど遅延します。利用には OpenAI API キーと利用料金（約 27 円／時間）が必要です。
画面音声録音は Zoom / Teams / Meet 等のオンライン会議の音声をマイク音声と同時に記録し、会議モードと同じく Whisper 系で文字起こしします。

Q. OpenAI API キーはどこで取得できますか？

OpenAI のサイト（https://platform.openai.com/api-keys）からアカウント作成 → 支払い方法登録 → API キーを発行という流れで取得できます。詳しい手順はアプリ内「設定 → API キーの取得方法」でもご確認いただけます。

よくある質問

Q. マイク録音モードで文字が表示されません

マイク録音モードはインターネット接続が必要です。Wi-Fi またはモバイルデータ通信の接続状態をご確認ください。また、初回利用時に表示される「マイクへのアクセス」「音声認識へのアクセス」を許可していただく必要があります。iOS の「設定 → VoiLog」から許可状態をご確認ください。

Q. 会議モードで「API キーが無効」と表示されます

OpenAI API キーが正しくない、もしくは OpenAI 側で支払い情報の登録（チャージ）が完了していない可能性があります。アプリの設定画面で「接続テスト」を実行してご確認ください。また、OpenAI のダッシュボード（Billing ページ）で残高をご確認ください。

Q. 画面音声録音モードで相手の声が録音されません

画面音声録音モードは iOS の「画面収録」機能を利用しています。録音画面で「ブロードキャストを開始」をタップし、表示されるピッカーで「VoiLog 録音」を選択し、マイクスイッチをオンにしてから「ブロードキャストを開始」をタップしてください。コントロールセンターの画面収録ボタンからではなく、必ずアプリ内のボタンから起動してください。

Q. 文字起こしの結果は安全ですか？どこに保存されますか？

録音した音声ファイルと文字起こしテキストは、お使いの iPhone 内のローカルストレージにのみ保存されます。当社のサーバーには一切送信・保存されません。ただし、文字起こし処理のために、ユーザーが選択したモードに応じて Apple または OpenAI のサーバーに音声データが送信されます。詳しくはプライバシーポリシーをご参照ください。

Q. OpenAI API の料金はどのくらいかかりますか？

本アプリが使用する gpt-4o-mini-transcribe モデルは、1 時間の音声で約 27 円程度の料金です（2026 年 5 月時点）。1 時間の会議を文字起こししても 30 円弱というイメージです。最新の料金は OpenAI の料金表（https://openai.com/api/pricing/）でご確認ください。

Q. API キーを削除したい・別のキーに切り替えたい

アプリの「設定」画面で、保存済みキーの右側にある「削除」をタップするとキーチェーンから完全に削除されます。新しいキーを貼り付けて「保存」すれば差し替えられます。

Q. 録音履歴を削除するには？

録音一覧画面で「編集」をタップし、削除したい録音を選んでください。アプリをアンインストールすると、すべての録音データ・文字起こし・保存された API キーが端末から削除されます。

Q. 対応機種を教えてください

iOS 16 以降を搭載した iPhone でご利用いただけます。
