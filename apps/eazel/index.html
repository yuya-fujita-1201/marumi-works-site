Eazel

制作・編集まわりの細かな手戻りを減らすための個人開発アプリ。 具体的な機能、販売ページ、サポート導線は確定後に追加します。

View directory → Contact studio

制作の手元に置ける、軽い作業補助ツールとして整備中。

Eazel は、制作や編集に関わる日々の作業を補助するクリエイティブツールとして準備中です。 現時点では公開前の紹介ページとして掲載しており、正式な機能名や対応プラットフォームは確定後に更新します。

想定している領域

アイデアの整理、素材や作業の扱いやすさ、制作フローの補助といった領域を中心に検討しています。 過度に機能を断定せず、公開準備が進んだ段階で具体的な画面や利用シーンを追加します。

公開準備について

販売ページ、プライバシーポリシー、利用規約、サポートページは準備中です。 外部ストアや専用サイトへの導線が決まり次第、このページから接続します。
